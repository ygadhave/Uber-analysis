# 🎵 Evolution of Popular Music Genres

This project explores the rich and dynamic world of music genres through **interactive visualizations**. By leveraging data from `music_data.csv`, we unveil trends, connections, and patterns that define the music industry's past and present.

---

## 🚀 Key Features

1. **Interactive Timeline**:  
   Visualize the rise and fall of music genres over time, highlighting pivotal moments in music history.
2. **Waveform Chart**:  
   Analyze the auditory identities of genres with their energy, danceability, and popularity.
3. **Chord Diagram**:  
   Discover collaborations and connections between genres.
4. **Network Graph**:  
   Explore the web of influence between artists and genres.
5. **Bubble Chart**:  
   Compare genre metrics like song count, average popularity, and duration intuitively.
6. **Stream Graph**:  
   Witness the ebb and flow of genre dominance over the years.


---

## 🖥️ Technologies Used

- **Frontend**: React, D3.js  
- **Styling**: CSS, Framer Motion for animations  
- **Data**: `music_data.csv`

## 🛠️ Installation & Setup

1. Clone the repository:
   ```
   git clone https://github.com/username/music-genres-visualization.git
   cd music-genres-visualization
   ```
2. Install dependencies:
```
npm install
```
3. Start the development server:
```bash
npm start
```
4 .Open your browser at ```http://localhost:3000```.


## 🎨 How to Use

- Interact with visualizations:
